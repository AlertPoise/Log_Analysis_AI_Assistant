## 开发注意事项

1. **每日提交**: 每天结束前提交代码到 Git
2. **代码审查**: 合并前必须进行代码审查
3. **测试覆盖**: 新功能必须有单元测试
4. **文档同步**: 功能完成后更新文档
5. **TODO 清理**: 实现功能后删除对应的 TODO 注释

## 快速开始开发

```bash
# 1. 选择要开发的功能
# 查看上面的任务清单

# 2. 创建功能分支
git checkout -b feature/功能名称

# 3. 实现功能
# 编辑对应的 Python 文件

# 4. 运行测试
pytest tests/ -v

# 5. 提交代码
git add .
git commit -m "feat: 实现 XXX 功能"

# 6. 推送代码
git push origin feature/功能名称

# 7. 创建 Pull Request
```
